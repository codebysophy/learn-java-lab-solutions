A new lecture comes out every Monday and the lab solution follows on Friday.

## Running a solution

The solutions use Java's compact source files (`void main()` and `IO`), so you need **JDK 25 or newer**.
There's no build step. Run any file directly:

```bash
java lab-01-pet-simulator/PetSimulator.java
```

Labs 5 and 6 each use a second file provided by the course (`SmoothieCard.java`, `CodeGenerator.java`). Keep it in the same folder and run the main file (`SmoothieShop.java`, `EscapeMazeMain.java`) the same way; Java picks up the other file automatically.

## Try it yourself first

You'll learn more if you solve each lab yourself before reading the solution.
