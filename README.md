# Learn Java in 30 Weeks: Lab Solutions

Weekly lab solutions for the free **Learn Java in 30 Weeks** series on [learn.java](https://learn.java).
A new lecture comes out every Monday and the lab solution follows on Friday.

| Lab | Topic | Solution |
| --- | --- | --- |
| 1 | Virtual Pet Simulator: variables, arithmetic, operator order | [PetSimulator.java](lab-01-pet-simulator/PetSimulator.java) |
| 2 | Space Fuel Tracker: compound operators, integer division vs. casting | [SpaceFuelTracker.java](lab-02-space-fuel-tracker/SpaceFuelTracker.java) |
| 3 | Music Fest Merch Inventory: comments, Javadoc, pre/postconditions | [MusicFestMerch.java](lab-03-music-fest-merch/MusicFestMerch.java) |

## Running a solution

The solutions use Java's compact source files (`void main()` and `IO`), so you need **JDK 25 or newer**.
There's no build step. Run any file directly:

```bash
java lab-01-pet-simulator/PetSimulator.java
```

## Try it yourself first

You'll learn more if you solve each lab yourself before reading the solution.
